## Key Takeaways
I learned how to customize and style an HTML audio progress bar using CSS pseudo-elements:

```CSS
.progress-bar::-webkit-slider-runnable-track {
    background-color: #ddd;
    border-radius: 100px;
    height: 0.2rem;
}

.progress-bar::-webkit-slider-thumb {
    appearance: none;
    height: 1rem;
    width: 1rem;
    background-color: #ffffff;
    border-radius: 50%;
    margin-top: -0.4rem;
}
```

## Challenges Faced
* **Finding Exact Icons:** It was difficult to find icons that matched the original Spotify interface.
* **Navbar Overlapping:** I ran into layout issues where elements in the main navigation bar overlapped.
